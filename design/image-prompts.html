Activity image prompts

Copy button அழுத்தினா, அந்த activity prompt-ஓட tracker style-ம் சேர்ந்தே copy ஆகும். ChatGPT, Gemini அல்லது Ideogram-ல paste பண்ணி image உருவாக்குங்க.

Image rules

  • Size: 4:3 landscape (1024×768). Subject நடுவில், ஓரங்களில் கொஞ்சம் இடம் விடுங்க.
  • Image-க்குள்ள எழுத்து வேண்டாம். Activity பெயரை app தானே மேல காட்டும்.
  • உண்மையான பிரபலங்களின் முகம் வேண்டாம். Kohli, Arnold மாதிரி யாரும் வேண்டாம், அனுமதி இல்லாம client app-ல போட முடியாது.
  • Save பண்ணும்போது file பெயர்: wealth-01.webp மாதிரி. WebP-ஆ, 150 KB-க்குள்ள இருக்கணும்.
  • Phase 2-ல Admin → Activities page-ல upload பண்ணலாம். Image இல்லைன்னா icon தானா தெரியும்.
